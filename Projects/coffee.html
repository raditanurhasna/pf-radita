Kopi Kala

Coffee ordering and loyalty program mobile application experience.

Project Overview

Problem

Many cafés still rely on various platforms such as Instagram, Google Maps, and WhatsApp to provide information and accept reservations. This forces customers to switch between apps, making the process of finding information and making reservations inefficient.

Goals

To design a café website that enables customers to view the menu, make table reservations, and access café information within a single integrated digital experience.

Pain Points

This project aims to design a café website that helps customers obtain complete information and make table reservations more easily. By integrating menu information, location, contact details, and reservation services into a single platform, the website is expected to provide a more practical, efficient, and convenient digital experience for customers.

Difficulty Finding Complete Information

Menu, operating hours, and prices scattered across various platforms such as Instagram, Google Maps, and WhatsApp make it difficult for customers to find information in one place, especially while on the go.

Reservation Process Lacks Convenience

Customers have to contact the admin directly via WhatsApp or phone, making the reservation process less quick and flexible.

Incomplete Menu Information

Available menus are often displayed only as photos without clear details on prices, sizes, or descriptions, making it difficult for customers to make choices before visiting.

Café Information Scattered Across Platforms

Customers have to open multiple applications to find café information, from menus and locations to operating hours and reservations.

Ideate

How Might We

Based on the pain points identified, I formulated How Might We (HMW) questions to transform each problem into a design opportunity. These questions served as a guide in exploring various solutions that focus on user needs.

Difficulty knowing table availability

How might we help customers know table availability before visiting the café?

Reservation process lacks convenience

How might we make it easier for customers to make table reservations before visiting without contacting the admin via WhatsApp?

Incomplete menu information

How might we present complete menu information so that customers can make choices before visiting?

Café information scattered across platforms

How might we provide all café information in one website so customers don't have to switch between platforms?

Information Architecture
